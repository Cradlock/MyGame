





# builder
Программа для сборки игры.
Включает в себя готовые исполняемые файлы,библиотеки и шаблонные ресурсы(фотографии,звуки,шейдеры...).\
Структура сборщика:
```
tools/{os}/{bitDepth}/{functional}/{files...}
tools/resources/{functional}/{files...}
```



# sdk 
Набор общих правил для компонентов: starter,plugins \
Включает в себя:
* Общие типы данных(статус коды, результаты,базовые типы...)
* Подпапки для модулей
    * `core` 
    * `logic` 
    * `plugins...`


# starter 
Основной код игры, включает в себя:
## app
Основной исполняемый файл:
* Загружает и запускает инициализацию `core`
* Загружает и запускает инициализацию `plugins`
* Запускает начало сценария из `logic`
---
Плагин менеджер,plugin_manager (статически слинкован с `app`). \
Использует __boost.dll__ , Загружает `plugins`

## core 
Ядро всей программы,представлен ввиде динамической библиотеки(слинкована с `app`) \
включает в себя:
### Сервисы 
* Logger: Логирование
* Resources: Работа с ресурсами
* Config: Работа с конфигурациями для разных модулей
* Tick: Работа с тиками
* EventBus: Схема общения между модулями


## logic 
Динамическая библиотека, задающая общий сценарий. 
* Создает основные события для `core` EventBus 
* ECS система 
* Plot graphs
* API для создания и изменения структур
